## Heads-up

**The page above is the complete content** — one sentence and one video link. The actual first-use
procedure exists only in the video and is **[Not in source]** in text form. Not transcribed.

What can be pieced together from elsewhere in the manual:

- **Powering on** — the power switch is **up for battery, down for USB**. The battery input accepts
  **3.7V–9V**. See [pins.md](pins.md#power).
- **Phone control** — first use relies on **connecting directly to the A3's own WiFi**, per the
  [networking page](networking.md), which contrasts itself with this method. Joining the A3 to an
  existing network is the alternative, covered there.
- **Charging** — **[Not in source]**. Nothing in the written manual describes charging; the USB port
  is documented as "power and data" but never as a charger.
